# 🚀 MBTI 테스트 웹 애플리케이션 소개

**AeriGeri Labs**에서 제작한 **MBTI 테스트 웹 애플리케이션**은 사용자가 간단한 설문을 통해 자신의 **MBTI 성향을 분석하고 결과를 확인**할 수 있는 서비스입니다.

사용자는 테스트 결과를 저장하고, 다른 사람들과 공유하거나 비공개 설정을 할 수 있습니다.

✅ 익명 소통 – 닉네임으로 자유롭게 의견을 나눌 수 있어요.  
✅ 무료 이용 – 누구든지 무료로 이용가능합니다.  
✅ 유용한 질문 – 기존 MBTI보다 더욱 실용적이며 공감되거나 재밌는 질문으로 구성됩니다.  

[👉 프로젝트 사이트로 이동하기](https://mbtitest-tau.vercel.app/)
